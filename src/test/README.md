# Canonical openhi2txt regression corpus

This directory contains one canonical fixture and one text/XML output pair per tested game. The dated snapshots inherited from the original hi2txt project have been coalesced; when a game had more than one fixture, the newest successful fixture was selected.

The expected files under `oracle/` were generated by openhi2txt. They are openhi2txt regression baselines, not compatibility snapshots for the original Java or C# hi2txt engines.

## Layout

```text
hiscore.dat       Current upstream MAME hiscore definitions
input/hi/         Canonical `.hi` fixtures
input/nvram/      Canonical NVRAM, EEPROM, and other persistent fixtures
oracle/           Expected openhi2txt `.txt` and `.xml` output
```
